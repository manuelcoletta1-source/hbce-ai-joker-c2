## Canonical position

FLYING SAUCER is not a real spacecraft, not a weapon system, and not an orbital military project.

FLYING SAUCER is a competition-safe strategic AI bot concept for Kaggle Orbit Wars, designed as a symbolic and technical demonstrator of governed orbital decision-making.

## Core thesis

AI is not only a threat.

AI is a powerful instrument, potentially the most powerful cognitive tool ever created by humankind, because it extends human speed, logic, mathematics, memory and strategic coordination.

If unguided, AI becomes weaponized acceleration.

If governed, AI becomes infrastructure for continuity, safety, energy, coordination and planetary resilience.

## Why Orbit Wars

Orbit Wars is the most coherent competition signal for the FLYING SAUCER concept because it places decision-making inside an orbital conflict simulation.

The theme is not only game strategy.

The theme is the future problem of orbit, resources, timing, control, expansion, defense and computable governance.

## Strategic interpretation

Orbit Wars is treated as a public strategic simulation, not as a military instruction layer.

The bot must learn to:

- perceive an orbital environment
- model planets, resources, timing and distance
- select targets
- avoid suicidal expansion
- defend valuable positions
- exploit weak opportunities
- produce traceable decisions
- improve through verification

## Public architecture

perception -> orbital_state -> strategy_matrix -> target_selection -> action_engine -> verification -> trace

## JOKER-C2 / MATRIX V role

JOKER-C2 is the runtime metaphor for governed decision control.
