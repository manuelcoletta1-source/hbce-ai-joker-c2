6. Self-pilot flow

The canonical self-pilot flow is:

1. Open HERMETICUM B.C.E. Platform.
2. Complete or reuse IPR onboarding state.
3. Access JOKER-C2 through IPR handoff.
4. Server-side runtime validates the IPR handoff.
5. JOKER-C2 recognizes the verified subject.
6. User submits an operational HBCE request.
7. Runtime evaluates SaaS tier.
8. Runtime evaluates risk and policy.
9. Runtime selects model level.
10. Runtime generates governed response.
11. Runtime updates IPR-bound memory if allowed.
12. Runtime generates EVT.
13. Runtime generates OPC when required.
14. Dashboard displays IPR, tier, model, memory, EVT, OPC and risk.
15. Evidence is captured in self-pilot proof bundle.

Short formula:

IPR → JOKER-C2 → tier → risk → model → response → memory → EVT → OPC → dashboard
