# IPR Identity

## Identity Primary Root

Version 1.0

---

# Purpose

IPR (Identity Primary Root) rappresenta il livello di identità governata utilizzato da AI JOKER-C2.

Ogni operazione del Mission Runtime è associata a un'identità verificabile.

---

# Objectives

- identificazione univoca;
- responsabilità operativa;
- continuità dell'identità;
- tracciabilità delle operazioni;
- auditabilità.

---

# Runtime Rules

Ogni missione deve essere associata a:

- Identity ID
- Authorization State
- Runtime Context
- Mission Context
- Audit Trace
